Interactive Domain & Backend Generator (Optional)

Enter your custom domain, Public WAN IP, and TCPShield CNAME below to automatically fill in the exact values in the steps below:

STEP 1 Open DiscoPanel
Prepare DiscoPanel & Port Forwarding
  1. Find your Public WAN IP on your DiscoPanel terminal (or click Detect above):
curl -4 ifconfig.me
  1. In DiscoPanel, verify server.properties has server-port=25565, server-ip= (empty), and prevent-proxy-connections=false.
  2. On your router, forward TCP Port 25565 → 192.168.0.119:25565.
STEP 2 Open TCPShield Panel
Create Network & Backend Set in TCPShield
  1. Log into panel.tcpshield.com and click Add Network (e.g. DiscoPanel).
  2. Go to Backends → Add Set (Name: DiscoPanel-Main) and paste your Backend IP:Port:
YOUR_PUBLIC_WAN_IP:25565
Proxy Protocol: Set to Disabled so all Fabric/Forge/NeoForge modpacks work immediately without extra plugins. (Only enable if you install TCPShield RealIP).
STEP 3 TCPShield Domains
Verify Domain & Link Hostname
  1. In TCPShield, go to Domains → Add Domain and enter yourdomain.com.
  2. Copy the tcpshield-verify=... TXT value, add a TXT Record for @ in your DNS provider, and click Verify in TCPShield.
  3. Go to Hostnames → Add Hostname, link to Backend Set DiscoPanel-Main, and enter:
mc.yourdomain.com
STEP 4 Open Cloudflare DNS
Point Custom Domain CNAME to TCPShield

Copy your Protected CNAME from TCPShield's Overview tab and create this DNS record in Cloudflare / your registrar:

Type: CNAME | Name: mc | Target: xxxxxxxx.tcpshield.net | Proxy: DNS Only (Grey Cloud)
Cloudflare Note: Keep the Cloudflare toggle on DNS Only (Grey Cloud) so TCPShield handles Minecraft TCP traffic.
STEP 5 (OPTIONAL PRO SECURITY) Firewall Lock-Down on DiscoPanel (Prevent Direct IP Bypass)
View TCPShield IPv4 List

Once players can connect via mc.yourdomain.com, run this on your DiscoPanel terminal (root@discopanel) so only TCPShield proxy nodes and your local LAN can connect to port 25565:

for ip in $(curl -fsSL https://tcpshield.com/v4/); do ufw allow proto tcp from "$ip" to any port 25565 comment 'TCPShield'; done && ufw allow proto tcp from 192.168.0.0/24 to any port 25565 comment 'Local LAN'
